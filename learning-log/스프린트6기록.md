2. 스트림에서 ::쓸때
   첫 번째 코드는 메서드 레퍼런스인 UserMapper::toDto를 사용하고 있습니다. 이 방식은 보통 정적(static) 메서드나 인스턴스 없이 호출 가능한 메서드를 참조할
   때
   사용됩니다. 그런데 여기서 toDto 메서드는 인스턴스 메서드이고, 실제 매퍼 빈은 userMapper 인스턴스로 주입되었기 때문에, 메서드 레퍼런스로 직접 호출하면 정적
   메서드로
   인식되어 호출되지 않습니다.

반면 두 번째 코드는 람다식을 사용하여 user -> userMapper.toDto(user) 형태로 작성되어 있습니다. 이 경우 주입된 userMapper 인스턴스를 통해
정상적으로 인스턴스 메서드가 호출되므로 올바르게 동작합니다.

즉, 첫 번째 방식은 메서드 레퍼런스가 정적 메서드에만 적합하기 때문에 작동하지 않고, 두 번째 방식은 인스턴스 메서드를 올바르게 호출하여 작동합니다.
