### 상황 :

org.hibernate.tool.schema.spi.CommandAcceptanceException: Error executing DDL "create table
message (id uuid generated by default as identity, created_at timestamp(6) with time zone,
updated_at timestamp(6) with time zone, content varchar(255), author_id uuid, channel_id uuid not
null, primary key (id))" via JDBC [오류: 식별 칼럼에 쓸 자료형은 smallint, integer, bigint 자료형만 쓸 수 있음]

Message 테이블을 만드는데 오류가 발생했다.

### 문제가 일어난 이유 : Id 자동 생성 전략 불일치

id uuid generated by default as identity,
식별자(PK)로 UUID 타입을 사용할 때 GenerationType.IDENTITY 전략을 지원하지 않기 때문이었다.

### 해결 : GenerationType.UUID 타입 이용

https://0soo.tistory.com/178

Springboot 3.x 이상의 버전을 사용하고 있었기 때문에, Id 자동생성 전략을 교체했다.
